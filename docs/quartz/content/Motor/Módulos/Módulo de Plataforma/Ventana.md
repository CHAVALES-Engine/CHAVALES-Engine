## Descripción:
Gestión de ventanas, inicialización y cierre
## Métodos públicos:

| Método               | Descripción                                  | Devuelve           |
| -------------------- | -------------------------------------------- | ------------------ |
| static int init()    | Inicializacion de la ventana                 | int = 0 (Correcto) |
| static int release() | Cierra la ventana y libera la memoria creada | int = 0 (Correcto) |
